# Research runs

Output of the `market-intel` agent. One directory per run, named `<YYYY-MM-DD>-<slug>`.

## Why runs are immutable

A run is a dated snapshot of what public sources said on one day. Editing a past run destroys
the only thing that makes this method cumulative: the ability to diff two runs six months apart
and see which competitor moved, which language spread, and which gap closed.

Corrections are a **new run** that references the prior directory. If a run contains an error,
note the correction in the new run's `00-scope.md`; do not rewrite history.

## Anatomy of a run

```
00-scope.md          Scope contract, agreed at Gate A
01-research-plan.md  Questions, source plan, stopping rule, known biases
02-competitor-set.md Who is in, who was excluded and why, how each was found
dossiers/*.json      One evidenced dossier per firm (schema v1)
03-comparison.md     GENERATED by build_comparison.py — never edit
04-patterns-gaps.md  Facts / Interpretations / Guesses / Absences
05-hypotheses.md     Three structurally distinct hypotheses
06-decision.md       Human verdict from Gate B, written after approval
audit.json           Machine result of the evidence audit
```

## Before you act on a run

1. `audit.json` says `"result": "pass"`.
2. You have hand-checked **five citations**: open the URL, find the quote. The audit proves a
   citation exists; only a human proves it says the thing. This is the single highest-value
   review action available and it takes about four minutes.
3. `02-competitor-set.md` exclusion list looks right to you. Every gap the run found is
   conditional on who was left out.
4. You can state, for each hypothesis you approve, the assumption that would kill it.

## Publication bar

Findings in a run are **internal by default.**

Before any statement about a named competitor leaves this repository — a deck, a proposal, a
post, a conversation with a prospect — it must be:

- `high` confidence, and
- sourced to a firm-owned or records-class page, and
- re-verified on the day it is used, because the page may have changed.

Naming a competitor's pricing or positioning externally carries commercial and legal exposure
that an internal note does not. The evidence standard for publication is a business decision,
not a technical one, and it belongs to the principal.

## Re-running

Re-run when the decision recurs, not on a schedule. A quarterly cadence produces four
directories and one insight. Re-run when: you are about to price something, name something,
or commit to a segment; or when a competitor visibly moves.
